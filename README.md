# GDG On Campus PW — Color Palette

Strona z paletą kolorów GDG On Campus PW dla Marketing Team.  
Kliknij dowolny kolor → hex skopiowany do schowka.

**Link:** [colors.gdgpw.pl](https://colors.gdgpw.pl)

## Kolory

| Rodzina | Odcienie |
|---------|----------|
| Blue    | 700 / 500 / 300 / 50 |
| Red     | 700 / 500 |
| Pink    | 300 / 50 |
| Yellow  | 700 / 500 / 300 / 50 |

## Uruchomienie

```bash
docker compose up -d
```

Strona dostępna na porcie `8097`.

## Stack

- HTML/CSS/JS
